Hệ thống Quản lý Mầm Non

1. Giới thiệu

Hệ thống Quản lý Mầm Non là một ứng dụng phần mềm hỗ trợ quản lý và
vận hành các hoạt động tại trường/lớp mầm non. Hệ thống hướng đến việc
số hóa quá trình quản lý trẻ em, giáo viên, lớp học và các thông tin
liên quan, giúp giảm thao tác thủ công và hỗ trợ theo dõi thông tin tập
trung.

Dự án được thực hiện trong khuôn khổ môn Công nghệ phần mềm (CNPM).

3. Mục tiêu dự án

Xây dựng hệ thống quản lý thông tin trẻ em tập trung.

Hỗ trợ quản lý lớp học và giáo viên.

Hỗ trợ theo dõi thông tin học tập, sinh hoạt và tình trạng của trẻ.

Giảm việc quản lý bằng giấy tờ hoặc bảng tính thủ công.

Xây dựng kiến trúc Frontend -- Backend -- Database rõ ràng.

Áp dụng Git/GitHub để quản lý mã nguồn và làm việc nhóm.

Sử dụng Docker để hỗ trợ triển khai và đồng nhất môi trường chạy ứng
dụng.

5. Công nghệ sử dụng

Frontend

ReactJS

HTML5

CSS3

JavaScript

Vite

Frontend chịu trách nhiệm xây dựng giao diện người dùng và giao tiếp với
Backend thông qua API.

Backend

Java

Spring Boot

Spring Web / REST API

Maven

Backend chịu trách nhiệm xử lý nghiệp vụ, xác thực, phân quyền và cung
cấp API cho Frontend.

Database

Microsoft SQL Server

SQL Server được sử dụng để lưu trữ dữ liệu của hệ thống như tài khoản,
trẻ em, giáo viên, lớp học, phụ huynh và các thông tin nghiệp vụ khác.

Công cụ và nền tảng

Git -- quản lý phiên bản mã nguồn.

GitHub -- lưu trữ mã nguồn và hỗ trợ làm việc nhóm.

Docker -- đóng gói và triển khai các thành phần của hệ thống.

Visual Studio Code / IntelliJ IDEA -- môi trường phát triển.

Postman -- kiểm thử REST API.
